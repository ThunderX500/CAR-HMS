# domain

Structure de haut niveau du domaine du CAR-HMS. Chaque sous-paquetage correspond
a un sous-domaine identifie dans la section « Sous-Domaines » du Livrable 1
(Groupe 22).

| Sous-paquetage  | Sous-domaine                                  | Classification |
| --------------- | --------------------------------------------- | -------------- |
| `hikeevents`    | Gestion des evenements de randonnee           | Coeur          |
| `trails`        | Requisition des donnees de sentiers de la CCN | Support        |
| `hikers`        | Gestion des randonneurs                       | Support        |
| `notifications` | Gestion des notifications                     | Generique      |
| `weather`       | Previsions meteorologiques                    | Generique      |
