# weather — Previsions meteorologiques

**Classification : generique**

Obtient, aupres d'un service externe, les previsions meteorologiques au point de
depart d'un sentier pour la date d'une randonnee, afin que le rappel de randonnee
puisse inclure un avertissement en cas de pluie ou de neige. Si les previsions
sont indisponibles, le rappel est envoye sans avertissement.

**Justification :** ce sous-domaine obtient les donnees meteo d'un secteur a
partir d'un service externe. Ces donnees ne sont pas propres au club et tout
systeme pourrait les utiliser de la meme facon. Il n'y a aucune regle propre au
club a developper.
